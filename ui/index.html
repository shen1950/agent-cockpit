    这块在干什么

    嵌进来的是本机 AgentHub 看板：项目 / 工作流波次进度 / Agent 负载 / 派工时间线 / 桌面桥接箱，还有可拖拽编排的工作流编辑器。 驾驶舱只负责把它嵌进来，数据都在看板那边。

    看板没起时这里会提示：在终端里运行 agenthub ui （默认 http://127.0.0.1:8766，只监听本机），起来后点上面「重新连接」。

    AgentHub 看板没有启动

    在终端里运行 agenthub ui（默认 http://127.0.0.1:8766，只监听本机）

    看板里有：项目 / 工作流波次进度 / Agent 负载 / 派工时间线 / 桌面桥接箱， 以及可拖拽编排的工作流编辑器。启动后点「重新连接」。

    API 与额度

      按「站点」管理：接入点和可用模型挂在站点上——一个站通常同时提供 OpenAI 兼容 / Anthropic 兼容 / DashScope 几种地址，一处填好，下面每条 key 都能用。 一个站点下可以放多个 key，各自记用途（Pot / WorkBuddy / QoderCN…）、额度与截止日期； 某条 key 确实走别的地址时，再在它自己的表单里覆盖。
