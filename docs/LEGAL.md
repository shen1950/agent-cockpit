## 本地网关

网关使用配置的账号凭据或 API Key 向上游请求，不扩大服务商授予该账号的模型权限、额度或使用范围。你仍需遵守各上游服务的条款、使用政策和适用法律；不同产品对自动化访问、账号共享、转售、客户端接口调用的规则可能不同。

接入密钥（`ac-…`）允许其持有者消耗授权范围内的额度。正常转发时，客户端使用的是网关接入密钥，上游服务接收的是对应的上游凭据；网关不需要把上游原始凭据交给下游客户端。客户端配置文件、备份与剪贴板仍可能保存接入密钥。

模型网关默认绑定 `127.0.0.1`。将它通过端口转发或其他代理开放出去会扩大访问范围。单独的手机远控功能由用户主动开启，具有自己的配对与访问边界，详见 [隐私说明](PRIVACY.md)。

图片代读会把图片发给所选视觉模型，再把文字描述发送给目标模型；备用路由可能把请求发给另一家已授权的上游。两者均可能产生额外费用。设置为「免费优先」只是本地选路偏好，不能让上游变成免费服务。详细配置见 [PROXY.md](PROXY.md)。
