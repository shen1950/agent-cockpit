# Agent 驾驶舱

国内 AI Agent 多开 / 赠送额度过期提醒 / 换号 / 本地反代 一体机。

架构为 Tauri 2、WebView2、Rust 后端和原生 Web 前端。账号管理等功能参考了 Cockpit Tools，网关交互参考了 Magpie；具体来源与许可见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
Windows x64 安装包和便携包均内置 Python。使用便携包时完整解压后运行 AgentCockpit.exe，并保留同目录的辅助程序。界面依赖 WebView2，首次使用签到、会话索引或用量采集时会在驾驶舱的数据目录展开运行时。

## 程序本体在哪

| 你要的 | 路径 |
|---|---|
| 双击就能用 | 解压便携 ZIP 后运行 `AgentCockpit.exe` |
| 安装包 | 以发布页实际提供的 NSIS 附件为准，安装后可从开始菜单启动 |
| 启动脚本 | `启动驾驶舱.bat`（优先 bin，其次编译产物，最后回退 Python 旧版） |
| 源码 | `ui/` 前端 + `src-tauri/src/` Rust 后端 |
| 第一代归档 | `legacy-python/`；它的构建产物存在 GitHub Release `v1-python-legacy` |

`bin/`、`src-tauri/target/`、`node_modules/` 都是可再生成的产物与缓存，已在 `.gitignore` 内，不入仓库；
删掉 `src-tauri/target/` 可回收约 6 GB，下次构建会重新生成。

## 快速开始

```bat
双击 启动驾驶舱.bat
```

从源码运行见 [开发指南](DEVELOPMENT.md)。共享工作区先登记任务，编译和测试走 `agsync build`，部署走 `agsync deploy`。

构建依赖：Rust（MSVC 工具链）+ VS Build Tools（C++ 工作负载）+ WebView2 Runtime（Win11 自带）。

## 三分钟上手

1. 左侧选一个 Agent（带「自动」的是扫描开始菜单新收录的，绿点=正在运行）
2. 点「＋ 添加账号」→ 六步向导：**登录方式 → 基本信息 → 数据来源 → 登录 → 额度 → 完成**
   - **登录方式**：官方登录 / 导入已有数据 / API Key 三种（未接通的 OAuth 授权、Token·JSON 会置灰列出，不做成点了没反应的按钮）
   - **数据来源**（关键）：**「接管本机的原有档案」**＝这个账号直接用该程序默认档案目录本身，不搬进数据根、也不复制一份；
     或「继承已有账号的数据」整份复制一份、或「全新空档（无历史对话）」。默认自动挑，卡片上会标出这个账号是哪一种
   - **可多开**（如 TRAE CN，原 TRAE SOLO CN）：建独立目录 → 启动后在窗口里登录 → 可与其它账号同屏
   - **仅可换号**（如 Qoder / Qoder CN / WorkBuddy / ZCode）：把默认入口指向这个账号（junction，零额外空间）；
     新账号默认建好就直接打开，之后从任何入口打开都是它，一次一个、随时切回
3. 在卡片「额度/设置」里登记总额、剩余与**过期日**——赠送积分的过期时间各家都不给接口，手动填是唯一可靠来源。Qoder / Qoder CN / WorkBuddy 有**本机直读**通道：点卡片「↻ 读余额」直接解客户端自己存的积分（不联网、不改产品文件），第一次读会把 userId 绑到这张卡，之后每次读都先校验本机登的是不是同一个号，防止把 A 号的余额记到 B 号头上；名字还是「账号N」这种占位符时，会顺手改成读到的真实用户名（如 `demo_account`），目录与换号记录一起跟着改
4. 临期不用常驻横幅占地方：30 天内的笔在顶栏聚成「临期 N」徽章（点开看明细），7 天内的启动时弹窗提醒一次；配了适配器/额度接口的账号每 30 分钟自动抓一次剩余
5. 官网与中转站的 Key 放「API 与额度」页统一管理；要拿它们做分发，到账号库下方「本地反代」把账号/Key 归进池子，再生成 `ac-…` 分发 Key 给客户端用（见下）

签到与额度后端随程序内置。更换电脑后先安装并登录需要使用的客户端，在侧栏点「重新扫描」，然后在签到页刷新状态。旧电脑上由 Windows DPAPI 加密的保管箱和登录凭据通常需要在新用户下重新建立。若提示内置组件校验失败，按错误提示修复运行时。

关窗不退出：驻留系统托盘继续监控，托盘菜单可退出或切换开机自启。

## 自测

```bash
cd src-tauri && cargo test                        # 单测 + 反代端到端（起服务 → 空池 502 → 日志 → 停止释放端口）
cd src-tauri && cargo test -- --include-ignored   # 再加真机用例（真扫本机 / 真读 agenthub / 池子与分发 Key 真往返）
```

真机用例会在结束时（含断言失败）把 `~/.agent-cockpit/config.json` 原样还原。

## 功能

| 模块 | 说明 |
|---|---|
| **自动发现** | 启动自动扫描或点击「重新扫描」时，从开始菜单、桌面快捷方式、安装记录、已知 CLI 和配置的 AI 安装目录查找入口。迁机后可用新位置修复失效的程序路径。新收录的程序在侧栏标「新」，未找到的原账号卡仍保留。 |
| 多开能力实测 | 启动后**真的去进程表核对**有没有带本实例目录的进程：核对失败说明该程序会把第二次启动转交给已有窗口（参数被丢弃），此时如实报错并把结论记进 `config.json` 的 `app_caps`，卡片自动改为换号入口。已实测：TRAE CN（原 TRAE SOLO CN，2026-10-11 升级改名）✅ 可多开；Qoder / Qoder CN / WorkBuddy ❌ 单实例接管，只能换号。「帮助 → 重置多开判定」可清掉重来 |
| 新建账号向导 | 五步：命名 → 选多开还是换号（按实测能力给默认值）→ 建目录并唤出登录 → 显示该账号目录的登录状态 → 登记额度与过期日 |
| 账号身份识别 | 扫描实例目录里的登录落点（`Cookies`、`Local Storage/leveldb`、`User/globalStorage/state.vscdb`、`auth.json` 等），卡片直接显示「从未启动过 / 已写入 N 个文件未见登录痕迹 / 有登录数据」，多账号不再分不清谁是谁 |
| API 与额度管理 | 独立页面登记各家官网 API 与中转站 Key：Base URL、Key（列表打码、点复制取原文）、类型、额度、过期日、备注；一键 `GET /v1/models` 测活并记录结果；**每条 Key 可配余额来源（OpenAI 官方 billing / one-api·new-api 中转站 / 通用额度接口 + 取值路径）一键抓余额，并随后台每轮自动刷新**；**「粘贴识别」：把整段 API 文本（名称/地址/Key/余额/过期日/模型…）粘进来点「识别并填充」，自动填好各项字段；规则一条都没认出来时会摆一个「让 AI 读一遍」按钮**（走 设置 → AI 识别 配的 OpenAI 兼容接口，要 API Key 才生效；只在你点它时才调，key 原文要求模型逐字照抄，填完仍要自己核对）；勾选「进反代池」只在**没建池子**的老式兜底模式下生效，正规做法是到「本地反代 → 池子」里把它勾进某个池 |
| 设置中心 | 顶栏齿轮进入，左侧七组：**个人资料 / 常规 / 外观 / 额度提醒 / 本地反代 / 高级 / 关于**。常规含开机自启、关闭窗口行为（收托盘或直接退出）、系统通知开关、界面刷新间隔、启动自动扫描；外观含主题、界面密度（舒适/紧凑）、字号；额度组可调黄红提醒阈值与自动抓取间隔；高级里能**手动添加程序**、重扫程序、重置多开判定、打开数据目录，还列出「已隐藏的程序」可一键恢复。改动写进 `config.json` 的 `settings` 并即时生效。设置页整块内容会随界面刷新重建，滚动位置自己记住并还原，不会把你刚滚到一半的「手动添加程序」弹回顶部 |
| **手动添加程序** | 没有安装记录或快捷方式的绿色程序，可以在「＋ 添加程序」中点「选择…」指定 exe、cmd 或 bat。名称留空时使用文件名。 |
| **扫描登记（本机盘点）** | 点击「扫描登记」后，在设置 → 高级查看与上次盘点相比新增、失踪以及路径失效的条目。常规「重新扫描」可更新侧栏，盘点基线保留到下次盘点。 |
| **账号额度与身份校验** | 按对应账号档案读取登录态和额度，区分服务端实时数据与本机缓存；发现身份不匹配时提示核对，不把另一账号的登录态自动当成当前卡片。实际数据来源与时间以卡片显示为准；服务端查询会联网，旧缓存不等同于当前余额。 |
| **WorkBuddy 用量与余额** | 本机会话用量和官方余额是不同数据：本机记录用于累计使用量，余额与到期日依赖对应账号可用的额度来源。读不到时显示未知或缓存状态，不用其他账号的数值补齐。 |
| **各家索引信息** | 客户端路径、登录形式与额度来源依产品版本变化；支持范围见 [SUPPORTED_AGENTS.md](SUPPORTED_AGENTS.md)，当前账号能否读取以界面实际结果为准。 |
| 无浏览器味道的交互 | 全局屏蔽 WebView2 默认右键菜单（返回/打印/另存为那套），换成自绘菜单：输入框里是剪切/复制/粘贴/全选，页面里是复制选中/刷新/打开设置/重新扫描 |
| 新手引导 | 首次启动自动播放 5 步引导（侧栏 / 账号卡片 / 向导 / 额度横幅 / API 与反代），**帮助与教程现在是 设置 里的一个分组**（不再是侧栏单独一页），随时进去点「重放新手引导」；内置五篇说明：多开原理与限制、换号怎么用、额度三种来源、API 与反代、自动发现与数据存放 |
| 多开 | 每实例独立数据目录：Electron 系用 `--user-data-dir`，CLI 系用 `CODEX_HOME`/`CLAUDE_CONFIG_DIR` 新开终端。手工适配 8 个（Qoder / Qoder CN / Qoder CN IDE / WorkBuddy / TRAE CN / ZCode / Codex / Claude Code），其余靠自动发现。**卡片的动作按状态收敛成一个主按钮**：运行中 →「■ 结束」；可多开 →「▶ 启动」；仅可换号且是当前账号 →「▶ 启动」；仅可换号但不是当前账号 →「▶ 切到本账号并打开」（换号与打开合成一步，不会再点出别的账号）。「还原默认」只在是当前账号时出现，「删除」在动作行最外侧（删前自动备份） |
| 实例级状态 | **「运行中」= 该账号有可见窗口**（`EnumWindows` 拿带标题的可见顶层窗口），不是数进程：Electron 关掉窗口后进程树常常还驻留，只数进程会出现"我没开它却显示开着、还挡住换号"。只有进程没窗口显示成琥珀色「后台驻留 ×N」，点「■ 结束」清掉。进程归属按命令行 `--user-data-dir=<实例目录>` 精确匹配，**且只有被「设为当前」的那个账号**才允许按程序级进程认领（否则没有换号记录时每张卡都显示同一个"运行中"，「■ 结束」也杀不到东西，kill 与运行判定同一套口径）。顶栏「运行中」= 有窗口的 Agent 程序数 |
| 启动子进程 | 一律先剥掉父进程注入的产品身份变量（`QODER*` / `CODEX*` / `CLAUDE*` / `TRAE*` / `GEMINI*`…）。从 Agent 的终端里启动驾驶舱时这些变量会一路继承下去，被启动的那个程序会以为自己是别的号——实测 Qoder 国际版因此弹「产物内联的产品是 qoder，当前运行身份是 qoder-cn」并拒绝启动 |
| 结束粒度 | 卡片「■ 结束」= 只杀该实例；进程表「结束全部」= 杀整个程序（含你正在用的窗口），带二次确认 |
| 账号数据来源 | 新建账号时可以**接管本机一直在用的那份档案**（原地登记：账号数据留在程序默认位置，不搬进数据根、不复制）、**继承已有账号的数据**（整份复制，原账号不动，缓存目录跳过）、或**全新空档**。默认规则：默认档案有数据且该程序仅可换号 → 接管；可多开/CLI → 复制（绝不动原档案）；都没有 → 从最近活跃的账号复制；再没有 → 空档。接管会把账号名挂到那个目录上，认错目录后续换号就拿它开刀，所以动手前一定先返回"要确认"，弹框把**目录绝对路径与体积**摊开给你看（认错目录曾把另一个产品的档案连根拔起，这道关是给那次补的）。**早期版本把接管进来的档案 rename 进 `instances/` 是设计错误**：用户天天用的档案离开了原位，`swaps.original` 还记成空串，「还原默认」只能还回空档案——这类历史账号在「账号设置 → 目录与数据」里有「归位」，同盘改名搬回原位。**删除账号前会先自动打一个 zip 备份**，原地账号不许从驾驶舱删（等于清掉本机档案） |
| 登录方式 | 向导第一步按 Agent 类型列出真正接通了的登录方式：**官方登录**（建档案 → 打开官方客户端 → 你登录 → 自动检测到登录数据）、**导入已有数据**（接管/复制，通常连登录都不用重做）、**API Key**（填上游地址与 Key，一次做完记台账 + 建账号 + 切换打开，「从上游获取」可直接拉模型清单）。**API Key 这一步只记台账**，不动配置文件；要真让某个程序用上这条 key，去「API 与额度」那行点「接入」（见下一行）|
| 一键接入自定义模型 | 台账里每条 key 都能点「接入」，把它的模型写进程序的自定义模型配置：Qoder / Qoder CN 写 `~/.qoder-cn/settings.json` 的 `providers`（条目形状与你手工加的那 8 条一致），WorkBuddy 写 `~/.workbuddy/models.json`（国际版共用这一份）。三道闸：**目标程序在跑就不写**（它退出时会把整份配置写回，塞进去的会被覆盖）、写之前原文件整份备份进数据根 `backups/inject/`、写回的条目 id 记在台账 key 的 `injected` 字段里，「撤掉」只删自己写过的那几条。**TraeWork CN 不写配置**：它本机没有明文 provider 落点（模型清单是 `state.vscdb` 里服务端下发的缓存），只能走反代；断开接入、停止反代或退出驾驶舱时，会按 base URL 把指向本机网关的缓存模型删掉，手工加的供应商不动 |
| 额度台账 | 登记总额/剩余/过期日/API Token；进度条 + 过期倒计时徽章（≤7 天红、≤30 天黄）；顶部横幅汇总临期额度，点击定位到对应 Agent，原生标题栏同步显示 `(N 笔临期)`。**支持「积分明细」多笔登记：每一笔积分有独立标签 / 剩余 / 总额 / 过期日，逐笔分别提醒，卡片汇总合计并显示最近一笔到期倒计时** |
| 额度自动抓取 | OpenAI 官方 billing 适配器、one-api/new-api 中转站适配器（`{base去v1}/api/user/self` 的 `data.quota - data.used_quota`），或通用 `quota_url` + 点路径取值；配置后每 30 分钟后台自动刷新，卡片显示上次抓取时间。**官网/中转站 Key 的余额也走同一套抓取器，参与后台自动刷新** |
| **本地会话用量** | 从本机 Agent 日志或数据库汇总可取得的 token 用量，区分实测和估算；来源、支持范围与缺失值处理见 [usage-statistics.md](usage-statistics.md)。 |
| 换号模式 | 把 Agent 默认档案目录做成指向实例的 NTFS junction，官方入口直接以该账号运行，**零额外磁盘占用**；原档案备份为 `*.cockpit-original`，一键还原；被官方后台进程锁定时点名提示并可确认强切 |
| 空间治理 | 每实例占用统计（MB）、清缓存（只删 Cache/logs/扩展缓存，保留登录态与设置） |
| 备份/恢复 | 实例数据目录 zip 备份，自动跳过缓存目录；恢复先解包到临时目录再原子替换 |
| 本地反代 | `127.0.0.1:8788` OpenAI 兼容转发：替换 `Authorization`、成功响应流式透传（保留 SSE）、带 CORS 预检与实时请求日志（日志含命中池与用了哪个分发 Key） |
| **网关接入与编制** | 模型反代总页管理来源、模型、上游组和接入密钥；最后一步可选目标 Agent，使用「接入本地网关」写入已适配客户端配置。每个 Agent 页也提供同一入口。高级设置可管理图片、上下文、供应商调度与计价，详见 [PROXY.md](PROXY.md) |
| 托盘与自启 | 关窗最小化到托盘（后台继续抓额度/提醒）；**托盘左键单击 = 打开主窗口**；托盘菜单：打开驾驶舱 / 重新扫描本机程序 / 立即刷新额度 / 本地反代（勾选启停）/ 打开数据目录 / 开机自启（勾选切换，写 HKCU Run）/ 退出；开机自启带 `--minimized` 只驻留托盘；启动后若有临期额度弹一次系统通知 |
| **协作（AgentHub 工作流看板）** | 侧栏「管理 → 协作」内嵌 AgentHub 本地看板（iframe，`127.0.0.1:8766`，只监听本机）：多 Agent 工作流的波次进度 / Agent 负载 / 派工时间线 / 桌面桥接箱，以及可拖拽编排的工作流编辑器。进页面时用 `no-cors` 探测看板端口活性（opaque 响应即视为存活），没启动就显示「终端跑 `agenthub ui`」的指引并每 5 秒自动重探，也可点「重新连接」手动重试；改动只在 `ui/` 前端（index.html / app.js / styles.css），不涉及 Rust 重编 |
| 单实例 | 重复启动不会开第二个窗口，而是把已有窗口唤到前台 |

## 界面设计

- **无边框窗口**：去掉原生 Windows 标题栏，把标题栏并进顶部设计条——整条可拖动、双击最大化，右侧自带 最小化 / 最大化·还原 / 收进托盘 三枚按钮（Segoe Fluent 图标，最大化时按钮图标随状态切换为还原）
  - **代价：`decorations: false` 的窗口上，WebView2 会把 `alert/confirm/prompt` 弹成另一个顶层窗口，鼠标点不动（只有 Enter/Esc 有效）**。所以全应用一律用页面内弹框 `ask()/askConfirm()/askText()`（`ui/index.html` 的 `#ask`），Enter 确定、Esc 取消、点遮罩取消；不要再引入任何原生对话框
- **双主题**：在「设置 → 外观」里选「浅色 / 跟随系统 / 深色」，存进 `config.json`，"跟随"实时响应系统 `prefers-color-scheme`；同页还有界面密度与字号
  - 深色：石墨底 `#0C0E14` + 琥珀金 `#C8956C`
  - 浅色：暖纸底 `#F5F3EF` + 深琥珀 `#A65E2E`（同一色系为浅色重调对比度，不是简单反色）
  - 11 组前景/背景对比度全部通过 WCAG AA（最低 4.61:1）
- **排版**：衬线标题（Noto Serif SC → Georgia 回退）+ 无衬线正文（Segoe UI / 微软雅黑）+ 等宽数字（tabular-nums），8pt 间距网格、12px 圆角、全程无渐变
- **响应式**：断点按 CSS 像素取值并考虑 Windows 150% 缩放；窄窗口侧栏自动收成短名图标条（Q / Q中 / QIDE / WB…），表格列改为省略号截断而非竖排换行。**侧栏分两段**：上面 Agent 列表自己滚，下面「管理」（协作 / API 与额度 / 设置）常驻不滚，收起按钮就摆在「管理」那一行右边（也可按 `Ctrl+B`、或在 设置→外观「侧栏形态」里定死），点过一次就以手动为准；手动收起不影响你拖过的展开宽度，再点开就回到原宽度
- **每个页面都是「左菜单 + 右内容」**：标题栏（← 返回 + 页名）钉在页顶不随内容滚，页面内部再分左菜单右内容——设置 11 个分组、API 与额度 是「快速登记 / 全部站点 / 每个站点」（点站点直接展开并滚过去）、协作 是「左说明 + 右看板」。侧栏在所有页面都保留，切页面的入口一直在手边
- **侧栏自己排位**：直接**按住某个 Agent（图标或名字都行）往上/下拖**，一条亮线告诉你将插在哪一项的上面/下面，松手就落位并写进 `settings.app_order`（收起成图标条时同样能拖）。右键菜单里的 置顶 / 上移一位 / 下移一位 / 置底 保留，键盘党和批量整理用得上。次序表整份交给后端 `app_reorder` 校验后一次写入，对不上（中间有新装/卸载/隐藏）就报错并回读，不会写出半截次序
- **工程质量**：HTML/CSS/JS 分文件、无内联脚本（CSP `script-src 'self'`）、DOM 全用 `el()` 构建不做 innerHTML 拼接、事件用 addEventListener 而非 onclick 字符串

## 接入本地网关

在 **模型反代** 总页配置上游来源、选择模型、启动网关并取得接入密钥，最后一步 **接入本地网关** 选择下游 Agent。每个 Agent 详情页只保留同名接入面板；模型来源与下游客户端是独立选择。

```
某个 Agent 的某个账号 ┐
                     ├─→ 池子「主力池」 ┐
「API 与额度」里的 Key ┘                 ├─→ 分发 Key ac-xxxx…  →  你的客户端
                     ┌─→ 池子「备用池」 ┘
「API 与额度」里的 Key ┘
```

1. **模型反代 → 上游组**：管理提供模型的账号与 API Key。
2. **接入密钥**：选择允许使用的上游组；未勾选组表示所有启用的组，需要收窄权限时应明确选择。
3. **接入本地网关**：选择目标 Agent、档案、密钥和模型。支持的配置可一键写入并在断开时恢复；未适配客户端按提示手工填入地址、密钥与模型 ID。
4. 在客户端发起请求后，查看 **实时路由** 中的上游尝试与结果。只刷新目录不会增加模型实测次数。

高级设置可指定原生读图或视觉代读，以及上下文窗口、最大输出、压缩阈值；供应商范围还包括并发、排队、RPM、备用模型和估算计价。设置范围、客户端支持限制、代读费用与调度细节统一见 [PROXY.md](PROXY.md)。

### 模型名一律带 Agent 前缀

客户端里填的 Model 一律是 `owner/模型` 形状：`trae/glm-5.3-flash`、`workbuddy/kimi-k3.1-pro`、
`qoder-cn/auto`、`astudio/spark-x2.6-4b`、`minimax/MiniMax-M3.1-Flash`、`qwenwork/flash`、
`catpaw/LongCat-2.0`……（面板的「模型 ID」表和「复制接入配置」给出去的都带前缀）。
同名模型（`glm-5.3-flash`、`kimi-k3` 每家都有）不带前缀就会在几家之间互相漂；
带前缀的请求只在属于这一家的上游里挑，报文转发前剥成裸名。已知前缀：
`workbuddy` / `workbuddy-intl` / `trae` / `qoder` / `qoder-cn` / `opencode` / `astudio` / `minimax` / `qwenwork` / `catpaw`。

### 自愈与一键的行为约定

- **千问办公**：本地桥（8765）没跑时，反代收到请求会当场把它拉起来（约 2~5 秒）；面板「获取模型ID」也会自动起桥。桥自带 2 小时空闲自退，下次请求再自愈，不留常驻空进程。
- **妙手**：2026-10-26 起改成**进程内云端直连**——反代带着 `~/.meituan-catpaw/auth.json` 的 accessToken 直接打妙手云端（nocode.cn + ai.catpaw.meituan.com），**不需要妙手桌面端在跑**，8789 桥进程和命名管道方案整体废弃。唯一要打开妙手的时刻：令牌过期后的重登（一键会替你把窗口拉起来）。一轮对话答完即删云会话，不留垃圾历史。

### 各家上游的差别（谁需要协议翻译）

| Agent | 上游协议 | 令牌来源 | 备注 |
|---|---|---|---|
| WorkBuddy 国内/国际、Qoder、AStudio | OpenAI 兼容 | 各家自己的档案 | 只换鉴权头，个别厂商要改 body |
| 千问办公 | OpenAI 兼容（本地桥 → 网页版 chat-ws） | `%APPDATA%\QwenWorkCN\auth-v2.dat`（桥自己解） | 桥挂了反代自愈拉起；桌面网关要 WASM 签名走不了，走网页版通道 |
| 妙手 | OpenAI 兼容（进程内 → 云端 create/agent-stream/SSE） | `~/.meituan-catpaw/auth.json`（accessToken） | 反代这层翻译云端 SSE；模型目录云端现拉，答完即删会话 |
| TRAE CN | 私有 SOLO 协议 | `storage.json`（byteCrypto） | 反代这层翻译 |
| **MiniMax Code** | **Anthropic 协议**（`POST /messages` + Anthropic SSE） | `~/.minimax/auth/<env>/<region>/mcode-public/auth.json`（OAuth） | 请求/响应/流式双向翻译，思考块映射成 `reasoning_content`；上游没有 `/models`，模型清单按客户端白名单静态给 |

MiniMax 的 OAuth 令牌寿命按小时算，反代会在到期前 60 秒自动换新并写回 `auth.json`
（连同 `auth-state.json` 的 generation 一起 +1，否则官方客户端会判「凭据与状态不匹配」）。
refresh token 是**轮换制**：换过一次旧的立刻作废，所以只在真过期时换一次、失败就退避，
不会反复重试。整族令牌被服务端撤销时，只能重新打开 MiniMax Code 登录一次。

|---|---|

### 编辑积分包（改名 / 截止日期 / 备注 / 自己加一个包）

厂商给的档名不一定认得（Qoder 官网把一类资源包统称「其他」），也不总给到期日。
每档右上角有一枚铅笔，「积分明细」底下还有「＋ 添加积分包」。

- **外层档**（卡片上那一行）：点铅笔只能改名称与备注。它的到期日是下面几十笔汇总出来的，
  手填一个会把「最近到期」顶掉，所以这一格不给填；没有逐笔的档（厂商只给汇总数）例外，那种能填。
- **内层每一笔**（点「查看明细 ›」之后，一行一笔）：每笔右端有自己的铅笔，
  名称、截止日期、备注三样都能改。30 多笔常全叫「平台赠送」，改哪一笔就是哪一笔（按厂商包 id 认人）；
  改过的标「改名」，日期改过的标「自填」，悬停能看到厂商原来给的那天。清空再保存 = 恢复厂商口径。
- **自己加一个包**：名称、总额、剩余、截止日期、备注；它和厂商那几档一起显示、一起参与临期提醒，
  标「自建」，弹窗里还能删掉。厂商压根不报的那份额度（比如活动送的）就靠它记账。
- 只在本机生效，不动厂商的任何数据，也不上传；落盘就是上面那个 `expiry.json`。

## 额度自动抓取示例

实例设置里填：

- 额度适配器：`OpenAI 官方 billing`（需 API Token，自动回填总额）
- 或额度接口：任意返回 JSON 的 URL + 取值路径（如 `data.remaining`，留空自动猜常见字段）

## 隐私

账号管理数据主要保存在本机，部分账号使用客户端原有目录。模型网关默认只绑定 `127.0.0.1`；手机远控由用户单独开启，可提供局域网或中继访问。登录、模型调用、图片代读、额度查询等功能会与相应服务交换数据。

数据存放位置、哪些操作会联网、凭据如何加密，见 [PRIVACY.md](PRIVACY.md)。
