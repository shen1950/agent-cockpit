# 用量统计

侧栏的「用量统计」读取本机记录，按天展示柱状图、曲线、Agent/模型占比和年度热力图。日期筛选、估算开关和 CSV 导出使用同一份按天汇总。原有账号详情中的消耗图也会优先使用这份本地记录。

## 数据口径

- 实测 Token 来自客户端保存的接口 usage 或请求用量表。优先采用 total 字段，缓存已包含在输入中的产品不再次累加缓存。
- 无 usage、但有可见对话文本的记录会单独估算。中文等 CJK 字符按约 1 字符/token，其余文本按约 4 字符/token。估算不含隐藏提示、反复发送的上下文、不可见工具内容和缓存，不能替代账单。
- 只有 credits 的来源保留原单位。用户填写 tokens/credit 系数后才能加入估算；没有默认通用兑换率。
- 同一 Agent 已有本地 Token 记录时，可能重叠的官方账单保留查看，避免再次换算加入总量。
- 默认档案与符号链接按实际目录去重。本机共用历史可能包含多个曾登录账号，标记为未按账号拆分；独立目录不会回落读取默认账号。
- 没有历史、文件不可读和数据缺失都不能解释为零消耗。页面显示覆盖状态和说明。

## 自定义接口

自定义模型是否进入图表，取决于客户端有没有保存 usage 或可估算的消息。ZCode 的 model_usage、WorkBuddy 的会话日志等可以保存第三方模型用量。官方 credits 图只覆盖其账单，不能据此推断第三方 API 消耗。

Qoder 官方说明，自定义模型费用由用户的 API 账户承担，模型调用不消耗 Qoder Credits；Repo Wiki 等内置服务有单独口径：
https://docs.qoder.com/qoder/custom-models

WorkBuddy 官方自定义模型说明：
https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model

## 监测

驾驶舱运行期间，每分钟读取一次本地用量；页面可设置刷新间隔或暂停页面刷新。暂停页面刷新不会停止后台观察。

Token/分钟来自两次采样之间今天用量的增量。监测图的横轴是本地时刻，纵轴是每分钟观察到的 Token 增量；该数字不是生成输出的实时速度。首次采样、跨天、来源变化、计数回退及间隔超过五分钟会重新建立基线。日志可能延迟落盘，批量落盘可能出现尖峰。

较长时间范围使用本机历史记录中的事件时刻重新分桶：近 24 小时以 5 分钟为一桶，近 7 天以小时为一桶，近 30 天以天为一桶。每桶的 Token 总数除以桶的分钟数得到平均消耗速率，包含输入、输出和来源所记录的上下文；这不代表模型输出速度。事件缺少具体时刻或来源没有记录时，不能推断为零；只提供日期的数据不会伪装成午夜的记录。

ChatGPT 与 Codex 可能读取同一份共享会话日志。全部 Agent 视图去重，单独查看一个 Agent 时显示它可读取的共享记录；这份历史不能准确归属到具体登录账号。历史窗口可在驾驶舱重启后重新读取已有日志，但无日志的时段无法补回。

回复平均吞吐只使用同时有输出 token 和请求耗时的记录，计算为输出总量除以这些请求的总耗时，包含首字等待。首字平均时间只使用实际记录的样本。缺少计时的产品不生成速度数字。

页面提供 Agent 和模型筛选，可选择单个 Agent 的各模型，或选择某个模型比较不同 Agent。没有模型名称的数据不能自动归到具体模型；不同供应商使用同名模型也需要结合来源查看。

## 本机尚未覆盖的来源

TRAE CN：目前找到的运行时记忆主要是摘要，不能代表完整对话或逐请求用量；未确认可按日期统计的 usage。妙手：本机尚未找到可按日期统计的请求 usage 数据库。Antigravity：本机会话库含二进制编码的步骤与元数据，目前尚未确认足够可靠的用量字段和归日方法。上述情况会继续显示数据不可用的原因，不以零代表消耗，也不会将摘要当作完整调用估算。
