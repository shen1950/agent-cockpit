# 隐私说明

更新于 2026-11-04。

AgentCockpit 的账号管理数据主要保存在本机，没有项目自建的遥测或云端账号服务。**本地保存不等于完全离线**：额度查询、登录、签到、模型调用、图片代读与用户开启的远控，会与相应服务或设备交换数据。

## 本机保存什么

默认数据根为 `%USERPROFILE%\.agent-cockpit\`；部分账号直接使用其客户端原有档案目录，也可在存储设置中调整数据根。常见文件包括：

| 内容 | 位置或说明 |
|---|---|
| 配置、上游组、接入密钥元数据 | `config.json` |
| 隔离的 Agent 档案 | `instances/`、`chatgpt-auth/` 等账号目录；原地接管档案仍在原目录 |
| 加密凭据 | `secrets/`，由 Windows DPAPI 保护 |
| 账号备份 | `backups/`，可含登录态、配置和会话数据 |
| 模型能力与供应商设置 | `gateway-model-settings.json`、`gateway-provider-settings.json` |
| 公共模型目录缓存 | `gateway-public-models.json` |
| 网关用量记录 | `gateway-usage.jsonl`，保存模型、时间与可取得的 token 用量 |
| 模型实测计数 | `proxymodel.json`，用于累计调用统计 |
| 失败诊断现场 | `proxy-fail.log` 及轮换文件 `proxy-fail.1.log`，可能包含截取的失败请求与响应 |

网关请求日志记录时间、模型、上游、状态等元数据。用量账本不保存提示词、图片正文或密钥；账号名称、模型名称、访问时间等元数据本身仍可能敏感。客户端与上游服务可能另有日志和会话保存策略。

**失败诊断日志有不同边界**：部分上游失败时，当前实现会截取请求和响应各前 4 KiB 保存到 `proxy-fail.log`，达到约 512 KiB 后轮换。片段可能包含提示词、工具结果、图片数据或内容中携带的秘密；截断不等于脱敏。反馈时不要直接上传整份文件，先检查内容并只提供必要的脱敏片段。不能把普通日志和用量账本“不记录正文”的性质套用到失败诊断文件。

## 凭据的读取与写入

本项目在相应功能中读取你可访问的客户端档案，并可能借助 Windows 当前用户权限或客户端接口读取登录态。导入、换号、恢复、写入网关配置以及部分令牌续期会修改对应文件。因此，不能把它视为“不解密、只读不写”的工具。

保管箱中的凭据使用 Windows DPAPI（CurrentUser）加密，可选主密码提供额外保护。这一保护**不覆盖所有副本**：客户端要求的配置、登录档案、导出备份、剪贴板及运行内存可能包含明文凭据。与当前 Windows 用户同权限的恶意程序仍可能读取运行中的数据；主密码不能防止所有本机攻击。

下游 Agent 接入本地网关时，会得到网关接入密钥；正常转发使用对应上游的凭据，客户端不因此取得上游原始密钥。请把接入配置和账号备份同样按密钥保管。

## 哪些操作会联网

| 场景 | 接收方 | 主要发送内容 |
|---|---|---|
| 官方登录、令牌续期 | 对应厂商的登录或授权服务 | 登录流程所需信息、凭据或续期令牌 |
| 额度查询、签到、模型测试 | 对应厂商或你配置的接口 | 账号凭据，以及查询或测试所需内容 |
| AI 文本/截图识别 | 设置中选择的模型网关 | 主动提供的文本或截图；如果材料包含密钥，密钥也会成为模型输入 |
| 网关转发 | 接入密钥授权范围内选中的上游 | 客户端请求内容、图片、工具结果及该上游所需凭据 |
| 图片代读 | 同一接入密钥下选中的视觉模型；随后是目标模型 | 视觉模型接收图片，目标模型接收代读文本；图片 URL 可能由上游另行获取 |
| 备用路由 | 配置且被该接入密钥授权的备用上游 | 重试所需的请求内容，可能涉及另一服务商 |
| 刷新公共模型价格 | `models.dev` | 获取公开目录的网络请求，不附带账号清单或 API Key |
| 用户安装可选桥接运行时 | 相应源码或软件包托管服务 | 下载请求，具体组件见第三方声明 |
| 打开项目链接 | 系统浏览器中的 GitHub 等目标站点 | 通常的网页访问；浏览器有自己的 Cookie 和隐私策略 |

本项目没有主动上传账号清单或用量账本的遥测功能，但不能据此承诺任何字段“绝不外发”：你提供给模型的文本、截图、工具输出或路径，都会随请求发给相应服务。只需离线解析时，可使用快速登记中的本机规则解析。

图片代读结果在本进程内有有限缓存；内联图片缓存按接入密钥、模型和图片摘要隔离，不把图片或描述写入用量账本。程序结束后内存缓存消失。

## 网关与手机远控的边界

模型网关默认仅监听 `127.0.0.1`，本机其他程序仍能访问端口，调用需要有效接入密钥。请勿把密钥放进公开仓库，也不要随意转发端口。

手机远控是另一项默认关闭的功能。开启后会提供局域网访问；如果另外配置公网中继，访问还会经过所选中继。配对设备能查看经筛选的额度与状态信息，并执行远控允许的动作。用完可关闭监听并撤销配对。详见 [远控设计](WEB_REMOTE_DESIGN.md)。

## 分享、移除与历史副本

分享截图、日志、源码或 Issue 前，请遮盖真实姓名、邮箱、手机号、账号 ID、密钥、家目录及私人会话内容。项目仓库地址与上游版权署名属于公开来源信息，应保留；不能为了隐私清理而删除依法需要保留的第三方版权声明。

卸载程序通常不会自动清除数据根。移除账号或数据前，先确认该目录是否仍被某个 Agent 使用；使用过档案切换或目录联接的账号，先通过驾驶舱恢复默认入口，并备份需要的会话。不要把删除数据根当作撤销云端账号授权的方法。

本地清理不能撤回已公开、同步或下载的副本。曾泄露的有效凭据应在对应服务撤销或轮换。发布前的源码、二进制、Git 历史与附件检查分别见 [PRIVACY_AUDIT.md](PRIVACY_AUDIT.md)。
