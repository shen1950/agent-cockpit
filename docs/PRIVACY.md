# 隐私说明

## 一句话

**数据都在你自己机器上。没有遥测，没有账号体系，不连作者的任何服务器。**

## 数据存在哪

默认数据根 `~/.agent-cockpit/`（Windows 即 `%USERPROFILE%\.agent-cockpit\`），可在「设置 → 存储」里搬家：

```
~/.agent-cockpit/
├── config.json               设置、反代配置（含上游组与分发 Key 的元数据）、换号记录
├── instances/<agent>/<实例>/ 每个账号一份完整档案（由对应 Agent 自己写入）
├── backups/                  账号备份 zip
├── secrets/                  加密保管箱（DPAPI 密文）
└── ...
```

各 AI Agent 自己的登录态存在它们各自的加密库里，**本项目只读不写**，也解不开它们的加密。

## 什么会发出网络请求

只有下面这几类，且目的地都是**你自己指定的**：

| 场景 | 目标 | 内容 |
|---|---|---|
| 额度抓取（适配器） | 你在实例设置里填的额度接口，或官方 API | 你自己的 Token |
| 额度抓取（网页） | 对应产品官网 | 你在那个 WebView2 窗口里自己登录的会话 |
| AI 识别（文本/截图） | **你配置的**模型网关（默认阿里云百炼） | 你主动粘贴的文本，或你主动选择的截图 |
| 反代转发 | 你池子里的上游服务 | 客户端的请求报文 + 你自己的凭据 |
| 每日签到 | 对应产品的活动接口 | 你自己的 Token |
| 打开项目链接 | `github.com` | 在浏览器里打开，不附带任何数据 |

**AI 识别是最值得注意的一项**：截图会发送到你自己配置的模型网关。介意就只用「快速登记」的本机规则解析通道——它离线运行，不产生任何网络请求，也不花 token。

## 什么绝不会发出

- 你的 Agent 账号列表、实例名称、备注；
- 你的 API Key 原文；
- 本地文件路径；
- 你的用量统计与聊天历史；
- 任何形式的设备指纹、崩溃报告、行为埋点。

本项目**没有**遥测端点，也**没有**任何收集数据的后端。

## 凭据怎么保护

两层：

1. **Windows DPAPI（CurrentUser）** 加密落盘——密文只有这台机器这个 Windows 账户能解，日常使用无感；
2. **可选主密码**——用 PBKDF2-SHA512 把主密码派生成 entropy 一起交给 DPAPI，于是必须**同时**有这台机器的 Windows 账户和正确的主密码才解得开。

界面与文档里只出现打码串；原文只在复制、编辑或发请求时由 Rust 侧取出，拼进请求头。

**边界要说清楚：** 不启用主密码时，能登录你这个 Windows 账户的恶意软件理论上可以取用保管箱内容。**在不信任的机器上，请启用主密码，或干脆不要用。**

备份 zip（`backups/`）里包含账号数据，**按密钥一样保管**，不要传网盘公开链接。

## 反代的额外注意

- 只绑 `127.0.0.1`，不对外网开放；
- 但**能访问本机的其他程序也能访问它**——分发 Key 泄露等于额度泄露；
- 请求日志记录时间、模型、上游与结果状态，**不落正文**，但日志本身仍属敏感信息；
- 详细风险见 [PROXY.md](PROXY.md)。

## 分享 / 反馈前请脱敏

贴 Issue、发截图、传日志之前，请先去掉：

- 账号名、邮箱、手机号；
- 密钥（`sk-…`、`ac-…`）与任何形似凭据的字符串；
- 家目录路径（`C:\Users\<你的名字>\…`）；
- 对话内容与截图里的个人信息。

## 删除数据

1. 在「设置 → 存储」里把数据根搬到你想要的盘，或直接删掉 `~/.agent-cockpit/` 整个目录；
2. 卸载程序本身**不会**自动删除数据根——这是刻意的（避免误删账号档案）；
3. 各 Agent 自己的档案目录在 `instances/` 下，删之前确认那个账号你不再需要；
4. 如果你曾把凭据贴到公开地方，**清除本地文件并不能撤回已下载的副本**，请到对应服务商处撤销或轮换。

## 与发布流程的关系

如果你要分发本项目的源码，请走 `python tools/privacy_check.py` + `export_public_source.py` 的发布门，详见 [DEVELOPMENT.md](DEVELOPMENT.md)。**任何扫描器都无法保证不存在全部个人信息**，正式公开前仍需人工检查截图、提交作者信息与附件。
