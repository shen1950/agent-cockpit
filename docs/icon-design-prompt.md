# AgentCockpit 图标设计提示词

将现有 `assets/icon-source.png` 作为参考图上传，再粘贴以下提示词：

请为桌面应用 AgentCockpit（Agent 驾驶舱）重新设计一个可长期使用的应用图标。它是一款管理多种 AI 编程工具、多个账号、模型连接与额度的桌面工作台。品牌关键词：掌控、有序、专注、可靠。

保留参考图的深石墨黑与暖琥珀铜金配色，但重新设计中心符号。以“驾驶舱中的导航核心”为概念：用一个有明确方向感的抽象 A 形轮廓，与一个简洁的中央控制节点结合，借助负空间自然表达导航和统一管理。符号要有独特轮廓，不要画真实飞机、方向盘、仪表盘或复杂网络连线。整体是成熟桌面软件的品牌标志，克制、精准、温暖，有工程工具的可靠感。

输出单个正视、居中、1:1 的应用图标，1024×1024。圆角方形底板使用接近 #101318 的石墨黑，主体使用 #C8956C 铜金，允许极少量 #E4B58A 高光。几何形体简洁、线条粗细一致、视觉重心平衡；符号占底板约 65%，四周留足安全区。可以有非常轻微的材质层次，但轮廓必须接近平面矢量设计，缩小到 32×32、24×24 仍然清楚，单色版本也应成立。

不要文字、字母标签、程序名、版本号、水印、展示样机、透视、场景背景或多图拼版。不要机器人脸、大脑、电路板、闪电、星芒、霓虹蓝紫渐变、强发光、玻璃拟态和厚重 3D。不要沿用 GitHub Octocat 或任何现有公司的商标。圆角底板之外透明，图标本体完整、不裁切。请直接输出一个完成度高的最终图标。

## 使用说明

图标本身不嵌程序名和版本号；这些由关于页排版，避免小尺寸模糊，也便于版本更新。选定方案后再生成 ICO 与不同尺寸 PNG，本次页面暂时使用原有图标。
