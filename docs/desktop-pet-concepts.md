# AgentCockpit 桌宠创意与绘制提示词

当前圆形悬浮球是轻量入口，不充当角色桌宠。下面四种角色供挑选，尚未生成或接入动画素材。参考用户提供的 Qoder、Trae、Buddy 录屏中的光标互动方式，角色外形采用独立设计。

## 1. 铜翼小鼯「栗栗」——优先推荐

暖奶油色肚子、铜棕色短绒毛、小圆耳，大头小身体。身穿极简飞行背心，胸前一枚三向导航扣。前肢与身体间一小片滑翔膜形成独特轮廓。不是戴机械头盔的猫，也不需要堆满航空装备。它像驾驶舱里负责看时间的小副驾驶，有点认真，又很容易被光标吸引。

鼠标移动：眼睛先跟随，头部稍晚转过去；鼠标突然靠近，耳朵竖起。拖起：双手抱住光标位置，滑翔膜张开，脚和尾巴滞后摆动。松手：落地轻蹲、尾巴回弹。贴边：探出半张脸，眼睛仍跟着光标。提醒：掏出一个小沙漏，用手指轻敲，不焦急跳个不停。静音：抱着尾巴打盹。

**直接发给绘图 AI：**

> 为 AgentCockpit 设计一个原创桌面宠物「铜翼小鼯」，用于 Windows 桌面上的透明背景动态角色。画一只成年气质但可爱的小蜜袋鼯：暖奶油色肚子、铜棕色短绒毛、小圆耳、黑巧克力色清楚的眼睛，头身比约 1.4:1，短手短脚、弯曲的蓬松尾巴，前肢两侧有小巧滑翔膜。穿一件轮廓极简的飞行背心，胸前只有一枚铜色三向导航扣，不写任何字。性格是认真、温和、略带好奇的小副驾驶。风格为干净的 2.5D 软陶与细腻短绒结合，体积简洁，颜色以奶油白、暖铜棕、少量深咖啡为主；保留清楚的外轮廓，不要大面积发光或透明毛边。全身完整，正面偏 10 度，双手放松，双眼朝前，脚底统一水平，四周留 12% 安全区，真实透明背景 PNG，1024×1024。缩小到 80–120 像素仍能识别耳朵、眼睛、滑翔膜和尾巴。不要文字、边框、圆角方形底座、场景、巨大投影、复杂道具。请先只给一张中性站姿定稿，不要把多种角色拼在一张图上。

## 2. 巡航小鳐「泊泊」——更轻、更有辨识度

一只悬浮的小鳐鱼，背部铜橙、腹部奶油白，侧面两片大鳍像柔软机翼。眼睛在前上方，尾巴末端有小小的圆形平衡环。没有机械臂和腿，整个身体像滑过桌面的飞行器。

鼠标移动：先转眼睛，再向光标方向倾斜鳍；远处移动只看，不擅自跟着跑。拖起：鳍顺着拖动方向折起，尾巴有拖曳感。贴边：把鳍卷起来，露一个眼睛。提醒：背部一枚小沙漏徽章亮起，轻拍气泡一次。空闲：慢慢扇鳍，关闭动画时完全静止。

**直接发给绘图 AI：**

> 设计一个原创桌面宠物「巡航小鳐」。主体是一只小巧、厚实、柔软的鳐鱼，不是写实海洋动物，也不是战斗飞船。身体像一枚奶油夹心小枕头，背部暖铜橙、腹部奶油白，两片宽而圆润的侧鳍像机翼，眼睛在前上方、清晰友善，尾巴短而柔软，尾端有一个极小铜色圆环。背上嵌一枚简洁的三向导航纹样，不要文字。采用精致的 2.5D 哑光软陶风格，几何轮廓大而简洁，避免亮面塑料和复杂机械零件。全身悬浮姿态，正面略俯视 10 度，鳍自然展开，双眼朝前；不用背景、不画地面投影，真实透明 PNG，1024×1024，四周留 12% 安全区。角色缩小到 96 像素仍要看清眼睛和鳍的方向。只画一只，不要图标底板，不要水花、星空、发光拖尾。它的用途是温和地提醒用户积分即将到期，气质安静、聪明、有一点调皮。

## 3. 时间寄居蟹「刻刻」——把到期提醒融进角色本身

奶油色小寄居蟹背一个不对称的铜色沙漏壳，透明窗里只有几颗大沙粒。两只短眼柄分别看光标；小钳子用来敲壳和举便签。轮廓由“大壳＋小脸＋两只小钳子”组成，避免真实蟹腿的复杂感。

提醒时敲两下沙漏壳，拖起时缩脚，贴边时侧身钻进去。未来便签功能可让它从壳里抽出一张卡片。时间状态由气泡文字准确表达，沙漏只负责动作，不用沙量暗示未经计算的剩余时间。

**直接发给绘图 AI：**

> 为桌面提醒应用设计原创角色「时间寄居蟹」。一只可爱的奶油白小寄居蟹，大头、两只短短的灵活眼柄、深棕色大眼睛、两只圆钝的小钳子，身体只露出两对短脚，避免写实昆虫般的密集腿。背上是偏圆的不对称铜色沙漏壳，壳占角色体积约一半，有一小块透明窗，窗内是少量大颗粒金色沙子，壳外保留简洁导航刻纹。角色看上去像认真管理时间的桌面小管家，友好、踏实，不焦虑。风格是干净的 2.5D 哑光玩具质感，铜色、奶油白、深咖啡三种主色，外轮廓清楚，拒绝繁杂齿轮。正面三分之四视角的完整站姿，眼睛朝前，四周留 12% 空间，透明背景 PNG 1024×1024。不要文字、数字、场景、图标方形底座，不要画多只。优先保证缩至 96 像素时沙漏壳、眼睛和钳子仍清晰。

## 4. 折纸信使「折折」——适合以后加入便签

一只由奶油色厚纸折成的小鸟，铜色翅尖、深色豆豆眼，一张折起的便签构成尾巴。大折面而非复杂折纸。它衔着提醒卡出现，空闲时整理翅膀，光标靠近时歪头。比软萌绒毛角色更克制，也更适合扁平简洁的界面。

**直接发给绘图 AI：**

> 设计一只原创的桌面便签伙伴「折纸信使」。奶油色厚纸折成的小鸟，圆润的大头、两枚深咖啡色豆豆眼、短喙、铜橙色翅尖，一张折起的便签形成短尾巴，两只极简小脚。使用少量大的折面表现结构，纸边清楚，略有纸张纤维质感但不要噪点。它像安静而机灵的桌面信使，不是写实鸟，也不是复杂的千纸鹤。3D 纸艺与平面图形之间的简洁风格，奶油白和暖铜色为主。画完整的中性站姿，眼睛朝前，翅膀自然收起，留出未来展开翅膀的空间，四周安全留白 12%，透明背景 PNG，1024×1024。不要文字、水印、场景、底板、巨大阴影；缩小至 80–120 像素仍有清楚的眼睛和翅膀轮廓。先只画单个角色定稿，不要生成角色合集。

## 定稿后再发：动作与拆层提示词

先确定一张中性角色，之后每次都把同一张定稿附给绘图 AI。不要分别从文字重新生成各动作，避免角色长相漂移。

> 严格沿用附件角色的身份、比例、材质、服装、颜色和镜头角度，为桌面动画制作素材。角色中心、脚底基准和画布尺寸保持一致，真实透明背景，每帧不得裁掉耳朵、尾巴、翅膀等部位；只让要求的部位运动，不加入新的饰品或文字。本轮输出【填入一个动作】的逐帧 PNG，编号连续，所有帧尺寸一致。动作前后衔接自然，空闲循环的首尾状态一致。请同时给一张小尺寸预览，确认缩至 96 像素仍清晰。

动作依次制作：

| 动作 | 建议帧数 | 设计要求 |
| --- | ---: | --- |
| 中性待机 | 6–8 | 极轻的呼吸，不持续左右移动位置 |
| 眨眼 | 4 | 睁眼、半闭、闭眼、恢复 |
| 看光标 | 9 个姿态 | 中心与八方向；瞳孔可独立移动，头部跟随幅度小 |
| 被提起 | 4–6 | 四肢收起或抱住，尾巴/翼膜滞后，锚点稳定 |
| 松手落下 | 4–6 | 一次轻微缓冲，不跳离用户放置的位置 |
| 临期提醒 | 6–8 | 举沙漏或小卡片、轻敲一次，然后回待机 |
| 贴边探头 | 每边 4 | 上下左右分别设计，不直接把角色翻得头朝下 |
| 安静休息 | 4–6 | 闭眼、慢呼吸；减少动画设置下使用单帧 |

用于实际光标跟随时，另要求分层透明 PNG：身体、头部、左眼白、右眼白、瞳孔、眼皮、尾巴/翅膀、提醒道具。每层必须保持同一完整画布与坐标，不能自动裁边。瞳孔与头部位移由程序计算；角色不需要追着光标在桌面上乱跑。

交互原则：注视跟随幅度有限、拖动优先、点击和拖动分开、通知不抢焦点；全屏安静、尊重减少动画、退出可恢复。两个提醒入口共用稍后/静音状态。四个角色可先各画一张静态定稿，再决定制作哪一个的动画，避免先做四套帧浪费工作。
