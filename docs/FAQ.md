# 常见问题

## 安装与启动

**Q：双击 exe 没反应 / 窗口一闪就没？**
先确认 WebView2 Runtime 已安装（Win11 自带，Win10 可能缺）。再试着从命令行启动，看有没有报错输出。若之前装过旧版，把旧 exe 彻底退出再开新的——exe 在运行时无法被覆盖，但可以被重命名，部署时就是这么换件的。

**Q：需要装 Python 吗？**
不需要。用量采集的运行时随程序内置，首次使用时会在数据目录解压。第一代 Python 原型放在 `legacy-python/`，仅作存档。

**Q：关掉窗口程序就退了吗？**
没有。关窗后驻留系统托盘继续监控额度。要彻底退出请用托盘菜单的「退出」。

## 认不出我的 Agent

**Q：侧栏里没有我装的程序？**
在侧栏点「重新扫描」，然后到设置 → 高级检查隐藏项。仍找不到的绿色程序可用「＋ 添加程序」直接选中可执行文件。

**Q：换电脑后能直接签到吗？**
先在新电脑上的对应客户端登录，再点签到页的刷新按钮。内置后端不需要另外安装 Python 或 agenthub。Windows DPAPI 保护的旧凭据通常不能跨机器或 Windows 用户解密。WorkBuddy 5.6 以后需要保持官方客户端运行，驾驶舱会用本机 `keyblob` 校验从客户端只读恢复的密钥，并把通过校验的结果存进当前 Windows 用户的 DPAPI 保管箱。

**Q：会不会改我的程序文件？**
不会。本项目**不修改任何 Agent 的配置文件**，只做启动、进程管理与档案目录隔离。

## 多开与换号

**Q：为什么有的能多开、有的只能换号？**
由内核实测判定。支持 `--user-data-dir` 的 Electron 系可以多开（各自独立目录）；只能单开的用 NTFS junction 把默认入口指到当前账号目录，切换时改指向——零额外空间，对话记录跟着账号走。

**Q：换号之后对话记录丢了吗？**
没丢，跟着账号档案走。切回去就回来了。

**Q：切回默认账号后提示「目录链接还在」？**
说明原来的档案目录还是 junction。删掉那个链接、把原目录改回原名即可，不动数据。

**Q：启动失败、说忽略启动参数？**
有些产品固定忽略 `--user-data-dir`，属于不支持多开。先换号再启动——界面会直接指路，不再让你白试。

## 额度与签到

**Q：额度显示「未知」是什么意思？**
读不到，不是 0。本项目在拿不到左/总数时一律报未知，**绝不用 0 冒充余额**——0 会被误读成「额度用完了」。

**Q：提示的是旧数据？**
缓存数据会标注来源时间，且**不产生临期提醒**。想要实时值请点刷新，走服务端接口。

**Q：签到显示已领完，还要不要点？**
要分情况：「已领完」≠「今天不用领」。领取日志保留一年，可按今天/7 天/30 天筛，也能导出 CSV 对账。没立刻到账的积分会自动盯着。

**Q：打卡会不会花积分？**
不会，走限免模型（step-5-preview → hy3）。

**Q：为什么某个账号的签到状态和另一个不一样？**
签到是**按账号实例**算的，每个实例各看各的，不用先切号才看得到另一个。

## AI 识别

**Q：一定要配 AI 吗？**
不一定。「快速登记」的本机规则解析优先、离线、零 token，能覆盖大部分排版。规则解析失败时才需要多模态兜底。

**Q：两个模型怎么选？**
文本模型解析粘贴的 key 清单（小快模型即可）；截图模型必须是视觉模型。默认 `qwen-flash` / `qwen-vl-flash`。

**Q：截图会被上传吗？**
会发到**你自己配置**的模型网关，不经过作者的任何服务器。介意就只用本机规则通道。

**Q：识别卡住 / 连点没反应？**
同一时间只放行一次识别，连点会被直接挡掉。看右下角的常驻进度（连接中 / 模型输出中 · 已收 N 字）。

**Q：同一条 key 登记了两次？**
落盘时会自动合并，不会重复。

## 反代

**Q：客户端连不上 8788。**
三查：反代是否已启动；地址是否 `http://127.0.0.1:8788/v1`；本机代理有没有劫持 `127.0.0.1`（curl 加 `--noproxy '*'` 验证）。

**Q：401 / 403。**
分发 Key 被停用或删了；或者这把 Key 允许走的池子里没有可用上游。

**Q：模型不存在（404）。**
Model 名必须带 Agent 前缀，如 `trae/glm-5.3-flash`。同名模型不带前缀会在几家之间互相漂。

**Q：Codex 桌面端接不上？**
Codex 走 Responses 协议（`POST /v1/responses`）。进站层已支持，不需要你再做协议转换。

**Q：用反代会不会封号？**
有可能。多数产品条款禁止账号共享与自动化访问。**这是你自己要判断并承担的风险**，详见 [PROXY.md](PROXY.md) 与 [LEGAL.md](LEGAL.md)。

**Q：反代能不能给别的机器用？**
技术上绑的是 `127.0.0.1`，不对外网开放。要跨机用需要自己做端口转发——**强烈不建议**，等于把额度钥匙挂在公网上。

## 数据与卸载

**Q：数据在哪？**
`~/.agent-cockpit/`。设置 → 关于与更新 → 「打开目录」可以直达。

**Q：能搬到别的盘吗？**
能，设置 → 存储 → 数据根搬家，旧位置留回滚点。

**Q：卸载会删我的账号档案吗？**
不会。卸载只移除程序，数据根保留——这是刻意的，避免误删档案。确认不要了再手动删目录。

**Q：怎么彻底退出并清理？**
托盘菜单退出 → 删 `~/.agent-cockpit/` → 卸载程序 → 如需，删各 Agent 的 `instances/` 下残余目录。

## 其他

**Q：有手机端吗？**
有 Web 远程控制（M1）：手机扫码进 `mobile.html`，能看额度、一键刷新、每日签到。换号/删除/搬家/反代管理**一概不在**手机端白名单里。监听默认关闭，需手动开启，配对码 10 分钟一次性。

**Q：支持 macOS / Linux 吗？**
当前只做 Windows。项目依赖 NTFS junction、DPAPI、Win32 API 与 WebView2 cookie 读取，跨平台不是简单重编译能解决的。

**Q：怎么反馈问题？**
见 [SECURITY.md](../SECURITY.md) 报安全问题；一般问题走 [Issue](https://github.com/shen1950/agent-cockpit/issues)，附版本号与复现步骤，**先脱敏**。
